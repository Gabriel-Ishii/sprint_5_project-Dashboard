# sprint_5_project-Dashboard

**Sprint 5 Project – Data Science: Developing and Deploying a Web Dashboard in the Cloud**

## Descrição do projeto

Este projeto consiste no desenvolvimento de um aplicativo web interativo para explorar e analisar dados de anúncios de veículos usados.

O aplicativo permite visualizar a distribuição e a variação dos preços dos veículos, além de analisar a relação entre o preço e características como marca, ano de fabricação e quilometragem.

## Funcionalidades

O dashboard oferece as seguintes funcionalidades:

- Visualização de uma amostra aleatória de 20 veículos do conjunto de dados.
- Histograma da distribuição dos preços, com possibilidade de selecionar as marcas apresentadas.
- Gráfico de barras com o preço mediano dos veículos por marca.
- Gráfico de dispersão para analisar a relação entre o preço e a quilometragem do veículo.
- Controle deslizante para limitar a quilometragem máxima apresentada no gráfico de dispersão.
- Gráfico de barras agrupadas com o preço mediano por marca e ano de fabricação.
- Controle deslizante para selecionar o intervalo de anos de fabricação analisado.

## Tecnologias utilizadas

- Python
- Pandas
- Streamlit
- Plotly

## Dados

O aplicativo utiliza o conjunto de dados `vehicles.csv`, que contém informações sobre anúncios de veículos, incluindo preço, ano de fabricação, modelo, condição, quilometragem, combustível e transmissão.

## Objetivo

O objetivo do aplicativo é facilitar a exploração dos dados de veículos usados através de visualizações interativas, permitindo identificar padrões de preços e relações entre diferentes características dos veículos.
